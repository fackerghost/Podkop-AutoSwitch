Первый предварительный выпуск Podkop AutoSwitch.

- Несколько HTTPS-подписок, дедупликация, native sing-box JSON и URI/base64.
- Проверки передачи HTTPS-данных, повторные попытки кандидатов и сохранение всех узлов.
- Sticky failover: 5 секунд, 3 ошибки, минимум 30 секунд между переключениями.
- Services → Podkop AutoSwitch: настройки, состояние, проверка пула и ручной выбор.
- Штатные UCI outbounds и Clash selector, резервирование и watchdog применения.
- IPK и сборка APK официальным SDK; автоматический установщик с SHA-256.

Аппаратные проверки: Cudy WR3000S v1 / OpenWrt 24.10.5 / Podkop 0.7.14 /
sing-box 1.12.22. Сетевые проверки — VLESS. Прочие протоколы проверены
конфигурационными fixtures, а не соединениями с реальными серверами.

Установка не включает автопереключение. Первое применение пула и изменение
его состава перезапускают Podkop. Поддержка всех форматов/версий не заявляется;
см. README и docs/TESTING.md. Статус preview: требуется дальнейшее длительное тестирование.
