Podkop AutoSwitch 0.1.2 — автоматический динамический пул и восстановление соединения.

- Достаточно добавить подписки и сохранить настройки. Отдельное применение пула
  удалено из LuCI; при включённом автоматическом режиме подключение и обновление
  выполняются самостоятельно. При новой установке режим включён. Существующая
  пауза enabled=0 при обновлении сохраняется.
- После трёх отказов выполняется параллельный поиск. Текущий проблемный узел
  исключается из выбора резерва; после выбора проверяется реальный HTTPS-трафик.
  Если кандидат не работает через основной маршрут, проверяется следующий.
- При отсутствии рабочего резерва поиск продолжается автоматически. Подписки
  обновляются повторно (по умолчанию каждые 60 с), новый состав подключается сам.
- При общем обрыве интернета выбор сохраняется. Прямые HTTPS-проверки обходят
  Podkop; после восстановления WAN работа возобновляется автоматически.
- Отказ одной подписки не блокирует обновление других; прежние узлы сохраняются
  в кэше источника. Неответившие серверы не удаляются и проверяются повторно.
- Короткая локальная ссылка `/autoswitch/`: компактная панель выбора серверов,
  задержек, обновления и проверки **без входа**. LAN-подсети IPv4/IPv6
  определяются автоматически; внешние источники и сторонние Host отклоняются.
- Независимые порты проверок, восстановление устаревших блокировок, отображение
  реального процесса монитора, состояния синхронизации и ожидания WAN в LuCI.

Первое подключение и изменённый состав пула требуют штатного перезапуска Podkop
с резервированием и watchdog. Обычная смена сервера выполняется через API.
Проверки: Cudy WR3000S / OpenWrt 24.10.5 / Podkop 0.7.14 / sing-box 1.12.22,
реальный отказ в изолированном ядре, WAN-сценарии с подменой сетевой границы,
частичный отказ подписок, непрерывный поиск и параллельные проверки 29 узлов.
APK собирается SDK 25.12.0; аппаратная проверка APK не выполнена. Выпуск preview.
